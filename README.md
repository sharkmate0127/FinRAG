# FinRAG — 金融研报智能问答系统

基于开源大模型 + RAG（检索增强生成）技术的金融研报问答系统。
用户上传金融研报 PDF 后，可针对研报内容进行智能问答，支持数值推理、
引用溯源，并可调用工具查询实时股价与财务数据（Agent）。

## 技术栈
Python / LangChain / ChromaDB / FastAPI / Gradio / Qwen2.5-7B / Ollama / AKShare
