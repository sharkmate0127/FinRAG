## 二、P0 分步操作指南（每步给可复制命令）

> 全程在 VS Code 打开 `E:\finrag\FinRAG`，终端用 PowerShell。
> 三行开头咒语（每开新终端先跑）：
> ```powershell
> cd E:\finrag\FinRAG
> .venv\Scripts\activate
> $env:HF_ENDPOINT = "https://hf-mirror.com"
> ```

### P0-1：跑完 top=10 实验，定稿检索参数

**背景**：top_k 从 5→8 已把 Recall 从 0.444 拉到 0.556（Precision 仍 1.0，说明还有放宽空间）。top=10 已在脚本里改好（9/2 改的），但当晚跑挂没重试。DeepSeek 现已充值。

**第 1 步** 确认脚本是 top=10：
```powershell
Select-String -Path eval_ragas_dual.py -Pattern "top="
```
预期输出：`ranked = hybrid_retrieve(q, top=10)` ← 看到 10 就对了

**第 2 步** 后台跑 api 通道全量（约 15-20 分钟，跑完自动通知）：
```powershell
$env:FINRAG_MODEL_MODE = "api"
python -u eval_ragas_dual.py 2>&1 | Tee-Object -FilePath logs/eval_ragas_api_71q_top10_full.log
```
> ⚠️ 期间别按 Ctrl+C；这是烧钱实验，一轮约几毛钱，别重复跑。

**第 3 步** 判定（看 `data/eval/ragas_api_results.json`）：

| 结果 | 动作 |
|---|---|
| Recall ≥ 0.60 且 Precision/Faithfulness 不掉 | ✅ **定稿 top=10**，把 `eval_ragas_dual.py` 里 top=10 保留 |
| Recall 升但 Precision 掉 >0.05 | 退回 top=8（Recall 0.556 已是最优平衡），改回 top=8 |
| Recall 还是 0.556 左右 | 说明 top_k 已到天花板，用 top=8 定稿，Recall 短板如实写进论文"局限与展望" |

### P0-2：最终版双通道统一重跑 + 更新全部报告

**原则：论文只认一组数字 = 「定稿 top_k」下的双通道结果。**

**第 1 步** P0-1 定稿后，把 `eval_ragas_dual.py` 的 top 值固定为定稿值。

**第 2 步** api 通道已跑（P0-1 第 2 步就是），补跑 **local 通道**（Ollama Qwen，GPU 独享，约 40-60 分钟）：
```powershell
$env:FINRAG_MODEL_MODE = "local"
$env:FINRAG_EMB_DEVICE = "cpu"   # 关键！embedding/reranker 走 CPU，防 8G 显存撞车
python -u eval_ragas_dual.py 2>&1 | Tee-Object -FilePath logs/eval_ragas_local_71q_final.log
```
> ⚠️ 跑前确认：Ollama 托盘开着（`ollama list` 有 qwen2.5:7b）；跑完前别关电脑别休眠。
> 记忆：上次不加 `FINRAG_EMB_DEVICE=cpu` 在 53/71 崩过 CUDA error。

**第 3 步** 合并双通道报告：
```powershell
python make_dual_report.py
```
预期输出：`对比报告已保存：docs/双通道对比报告.md`（日期自动当天）

**第 4 步** 更新 README 评估结果段（把 Day27-28 的 10 题旧数字替换为 71 题最终双通道数字）。

### P0-3：提交仓库（一次 commit 收干净）

**背景**：当前 git 有 3 个已改文件 + 20+ 未跟踪文件（71 题评测集、eval 脚本、9/2 全部工作产物）。

**第 1 步** 确认要提交的内容，别把垃圾提交上去：
```powershell
git status
```
**第 2 步** 加白名单式提交（核心产物，不含临时文件）：
```powershell
git add ask.py rag_agent.py model_config.py eval_ragas_dual.py eval_recall_only.py make_dual_report.py
git add data/eval/qa_pairs_71_final.json data/eval/ragas_*.json data/eval/ragas_*.md data/eval/recall_top*.json

```
> 疑问文件先 `git add data/eval/qa_pairs_73_final.json` 这类历史版本看情况；.env 千万别 add（含密钥）。

**第 3 步** commit + 打 tag：
```powershell
git commit -m "feat: Day33 双通道RAGAS 71题评测 + 检索top_k实验(0.444→0.556) + 双通道对比报告"
```
