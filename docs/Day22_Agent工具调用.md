`test_tool.py` 的 `get_stock_price` 依次尝试：

1. **akshare 真实接口**（东财行情，联网）


## 4. Agent 核心代码（三句话讲明白）

### 4.1 告诉 LLM 有哪些工具（工具清单）

```python
TOOLS = [{
    "type": "function",
    "function": {
        "name": "get_stock_price",
        "description": "查询股票实时价格。支持 A 股（6 位代码）和港股（5 位代码）...",
        "parameters": {"type": "object", "properties": {"stock_code": {...}}, "required": ["stock_code"]}
    }
}]
```

### 4.2 Agent 主循环（核心思想）

```python
for i in range(max_iter):                       # 最多 5 轮
    result = call_llm(messages, tools=TOOLS)    # 让 LLM 看问题 + 工具清单
    msg = result["choices"][0]["message"]
    if msg.get("tool_calls"):                   # LLM 决定要调工具
        for tc in msg["tool_calls"]:
            tool_result = get_stock_price(args["stock_code"])   # 我们执行工具
            messages.append({"role": "tool", "tool_call_id": tc["id"], "content": tool_result})
    else:                                       # LLM 给了最终答案
        return msg["content"]
```

### 4.3 测试输出（真实运行）

```
[用户提问] 比亚迪 002594 现在的最新价？
[LLM 决定] 调用 1 个工具
  -> get_stock_price({'stock_code': '002594'})
  <- 工具返回: 比亚迪(002594) 最新价: 325.04 元（数据来源: 本地演示...）
[LLM 最终答案] 比亚迪(002594) 今日行情如下：最新价为 325.04 元，较基准价 320.45 元上涨 +1.43%...
```

> 亮点：LLM **自己判断要调工具**、**自己选对参数**、**看懂结果后组织自然语言**，还主动加了"数据来源为本地演示"的免责声明——说明它真的在理解，不是在背答案。

## 5. 面试话术（一页版）

**Q: RAG 和 Agent 有什么区别？**

> RAG 是 LLM **被动**看知识库回答，像开卷考试，答案都在书里；
> Agent 是 LLM **主动**决定要不要调外部工具，像开卷考试 + 允许用计算器。
> 我的项目两种都做了：研报内容类问题走 RAG（检索 1323 块研报文本 + 混合检索 + 重排），实时行情类问题走 Agent（LLM 自己决定调 `get_stock_price` 工具）。

**Q: 你如何保证 Agent 不失控？**

> 三个保险：① `max_iter=5` 死循环保护；② 工具描述写清楚参数和适用场景，减少 LLM 误调；③ 工具执行层做三级降级，网络失败不崩。
