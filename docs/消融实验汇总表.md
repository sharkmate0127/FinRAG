## 二、最终系统 RAGAS 全量评测（71 题，同基准权威数字）

> **这是论文引用 RAGAS 分数时唯一认的口径**：评测集 `qa_pairs_71_final.json`（71 题，reference 全部校对为研报原文，`ref_checked=71/71`），judge 固定 DeepSeek（裁判中立），embedding bge-large-zh-v1.5。

**71 题题型构成**：factual 事实 46 / numerical 数值 10 / agent 工具 7 / comparison 对比 4 / reasoning 推理 4

### 2.1 检索 top_k 扫描（DeepSeek API 通道）→ 定稿 top=8

| top_k | Faithfulness | Answer Relevancy | Context Precision | Context Recall | 判定 |
|---|---|---|---|---|---|
| 5 | 1.000 | 0.752 | 1.000 | 0.444 | 旧基线（块数不够） |
| **8（定稿）** | **0.947** | **0.800** | **1.000** | **0.556** | 最优平衡 |
| 10 | 1.000 | 0.816 | 0.907 | 0.556 | Recall 不再涨、Precision 掉 → 不采用 |

数据文件：`data/eval/ragas_api_results_top5.json` / `ragas_api_results_top8.json`（官方 `ragas_api_results.json`）/ `ragas_api_results_top10.json`

### 2.2 双通道对比（定稿 top=8）— v3.1「双通道」亮点

| 指标 | DeepSeek API | Qwen2.5-7B INT4（本地） | 方案预期 | 说明 |
|---|---|---|---|---|
| Faithfulness | 0.947 | **1.000** | API 0.80-0.90 / 本地 0.70-0.80 | 双达标 |
| Answer Relevancy | 0.800 | **0.873** | 0.75-0.85 / 0.70-0.80 | 双达标 |
| Context Precision | **1.000** | 0.909 | — | API 满分 |
| Context Recall | 0.556 | 0.556 | 未达 0.60 | 两通道相同 → 检索层瓶颈（见下） |

数据文件：`data/eval/ragas_api_results.json`（api top8）+ `data/eval/ragas_local_results.json`；汇总报告 `docs/双通道对比报告.md`

### 2.3 关键分析结论（论文可用）

1. **Context Recall 两通道完全一致（0.556 = 0.556）→ 检索层瓶颈铁证**：Recall 只取决于共享检索器，与生成模型无关（控制变量论证）。
2. **top_k 8→10 Recall 不再上涨 → 源头漏检**：漏掉的答案块未进入混合检索候选池（向量 n_results=20 / BM25 top20 源头），非精排块数问题。
3. **量化代价可见但可控**：INT4 Qwen 在数值/推理类上略逊（对比 API），日常开发用 API、离线演示用本地的调度策略有据可依。
